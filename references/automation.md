# 自动同步（可选）

先把实际情况告诉用户：**学校的统一登录一般撑不过一天**。实测登录后 5 到 16 小时就会过期，定时访问也续不了。
所以定时任务多半会碰到「登录过期」：它会跳过抓取，用已有材料把其余步骤跑完，然后提醒用户登录。
真正抓到新材料，通常还是靠用户收到提醒后说一句「同步课程」，在弹出的窗口里登录一下。

## 定时任务的提示词

不管用哪个工具，提示词都一样：

```
执行 PolyU 课程同步：使用 polyu-course-sync skill，按 auto 模式（mode=auto）跑完全部步骤。
这是无人值守运行：登录过期时不要打开登录窗口，跳过抓取，用已有材料跑完其余步骤；最后按 skill 的规则决定是否提醒我。
```

时间建议每周一两次，例如周一、周五 21:00。

## 在哪里建

- **Codex**：用桌面 app 的 Automations 建一个定期运行的自动化，填上面的提示词。
  - 也可以用系统自带的定时（macOS 的 launchd、Linux 的 cron、Windows 的任务计划程序），定时运行 `codex exec "<上面的提示词>"`。
  - 不论哪种，都要先按 SKILL.md「权限」一节改好 Codex 的沙盒配置：无人值守时没人批准在沙盒外运行。
- **Claude Code**：用 Claude 桌面 app 的定时任务（`schedule` skill 或 scheduled-tasks 工具）。要先按 SKILL.md「权限」一节加好允许规则：没人点「允许」时，只要有一步需要确认，整轮就会中止。

定时任务只在电脑开着、对应的 app 开着时运行。错过的那一次，有的工具会在下次打开时补跑。

## 提醒

auto 模式结束时，按 SKILL.md「汇报」一节的规则决定提不提醒：

- 有推送工具（例如 Claude 的 PushNotification）就用它；
- 没有就运行 `node "<S>/notify.mjs" "PolyU 课程同步" "<内容>"` 发系统通知。
